Stock Portfolio Tracker

About the Project

Stock Portfolio Tracker is a simple Python-based project that calculates the total investment value of a user's stock portfolio.

Features

- Enter the number of different stocks owned.
- Input stock names, prices, and quantities.
- Calculate individual stock investments.
- Calculate the total portfolio investment.
- Save the final investment result to a text file.

Technologies Used

- Python
- File Handling
- Conditional Statements
- Loops
- Basic Arithmetic Operations

How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run "stock_tracker.py".
5. Follow the instructions displayed in the terminal.

Output

The program displays individual stock investments and the total investment value. It also saves the total in "investment.txt".

Purpose

This project was created to practice Python programming, user input, loops, conditions, and file handling.
